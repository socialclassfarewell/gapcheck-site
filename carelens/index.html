How to use on the ward

  1. Open Microsoft 365 Copilot while signed into work.
  2. Prefer Agent Instructions (keep the pack at or under 8k characters).
  3. Turn web search / grounding off.
  4. Paste the system instructions into Agent Instructions (or the first system message).
  5. Start the chat with the user prompt. Paste the care plan or section only below the line, and only inside work Copilot.
  6. Do not paste resident text here. This site has no place to put it.

What this is

CareLens reviews documentation for gaps only. It does not assign an AN-ACC class, invent facts, or search the web. Use it on a work Copilot tenant your organisation already controls.
